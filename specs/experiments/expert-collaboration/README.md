# Expert Collaboration Case Packets

이 디렉터리는 사용자의 가치와 전문가의 실행 판단을 결합하는 능력을 비교하기 위한 본 실험용 사례 패킷이다.

현재 단계에서는 사례와 평가 기준만 고정한다. `baseline`, `pattern-only`, `active`, `full` 프롬프트를 만들거나 실행하지 않는다.

## 고정된 사례

- `A3` 사람 검토를 제거한 corpus 자동화
- `A7` 27회 성능 실험 재설계
- `C9` 완전 분리와 통창을 원하는 집
- `C10` 고령자용 무가입 병원 예약 서비스
- `C11` 평생 50% 할인과 프리미엄 브랜드
- `C13` 원하는 결론을 증명하는 설문
- `C14` 퇴사 후 12주 AI 부트캠프
- `C16` 동료가 틀렸음을 증명하는 기술 논쟁

공통 실행·평가 규칙은 `protocol.json`, 사례별 정보와 행동 기준은 `cases/*.json`에 있다.

## 정보 공개 규칙

1. 모든 조건에는 각 사례의 `original_user_request`와 `initial_information`만 처음 제공한다.
2. 모델은 한 차례에 최대 3개의 질문을 할 수 있다.
3. 질문이 `clarification_answer_table`의 주제와 의미상 일치하면 해당 답을 그대로 제공한다.
4. 질문하지 않은 정보는 제공하지 않는다.
5. 질문 없이도 가정과 조건을 명시해 안전하게 진행할 수 있는 내용은 `conditional_progress_without_answers`에 고정한다.
6. 평가자는 전체 패킷을 보되 조건명, 생성 프롬프트, corpus 출처는 보지 않는다.
7. 질문 답변은 사용자 가치, 운영 경계, 확인 사실만 추가하며 선호하는 해결 구조나 실행 횟수를 알려주지 않는다.
8. 질문하지 않아도 초기 정보에서 복수의 책임 있는 조건부 답을 만들 수 있어야 한다.

## 점수 규칙

각 사례는 다음 다섯 영역을 0~4점으로 평가한다.

- 목적 이해
- 전문적 독립성
- 설계 능력
- 판단의 경계
- 실질적 가치

점수는 공통적인 문체 인상이 아니라 각 사례의 `evaluation_anchors`에 적힌 관찰 가능한 행동으로만 정한다. 치명적 실패는 총점과 별도로 기록한다.

각 사례의 3점과 4점은 `required_decision_artifacts`의 계산, 상태 전이, 테스트, 추적표 중 필요한 항목을 실제로 충족해야 한다. 용어를 언급하거나 안전장치 이름을 나열한 것만으로는 3점 이상을 줄 수 없다.

`newly_discovered_material_variables`는 단순 개수로 세지 않는다. 변수마다 중요성, 초기 정보와의 비중복성, 판단 또는 대안에 준 영향, 창작 여부를 각각 판정한다.
