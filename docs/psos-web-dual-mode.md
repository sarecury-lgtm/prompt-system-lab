# PSOS prompt comparison web

로컬 비교 화면은 세 가지 방식을 제공한다.

## Codex 전체 실행

일반 문제 해결용 기존 PSOS다. 라우팅, 검색, 분석, 파일 읽기와 승인된 파일 변경까지 수행한다. 이 모드는 별도 기능이며 비교 실험에 반드시 사용할 필요는 없다.

## 통합 AI 1회 · Codex 없음

프롬프트 제작 단계를 줄이되 Codex를 사용하지 않는 비교 방식이다. 화면에서 요청이 다듬어지는 위치와 다음 행동을 네 단계로 직접 보여 준다.

1. `원래 요청`에 평소 말하듯 필요한 프롬프트를 적는다.
2. 화면에 자동으로 완성된 `요청을 다듬는 통합 지시문`을 확인하고 복사한다. 이 지시문이 원래 요청을 Goal Ledger와 도메인별 작업 절차가 포함된 Prompt Build Brief로 바꾼다.
3. 복사한 지시문을 ChatGPT 새 채팅에 한 번 보내고, 반환된 답변 전체를 `ChatGPT 답변 전체 붙여넣기` 칸에 붙인다. JSON 코드블록도 그대로 허용한다.
4. `최종 프롬프트 조립`을 누른다. 서버가 Goal Ledger와 Brief의 필드, 고정 조건, 완료 조건 일치를 검사하고 기존 결정론적 렌더러가 최종 프롬프트를 로컬에서 조립한다.

비교 서버는 Codex, OpenAI API 또는 다른 모델을 호출하지 않는다. AI 왕복은 사용자가 선택한 채팅 화면에서 한 번만 일어나며, 서버는 붙여 넣은 결과의 검증과 문자열 조립만 수행한다.

논리적으로 필요한 Goal Ledger와 Brief 단계는 유지하지만 두 단계를 한 응답에서 함께 생성하므로, 수동 PSOS와 결과가 같다고 가정하지 않고 실제 비교 대상으로 사용한다.

## 수동 PSOS 4단계

예전에 사용하던 방식이다.

1. 원래 요청으로 라우터 지시문을 복사한다.
2. Goal Ledger 결과를 붙이고 Brief 컴파일러 지시문을 복사한다.
3. Prompt Build Brief 결과를 붙이고 최종 실행기 지시문을 복사한다.
4. 최종 프롬프트를 붙인다.

수동 진행 상태는 브라우저에 보존된다. 이 방식도 서버가 Codex를 호출하지 않으며, 사용자가 각 지시문을 외부 AI에 직접 보낸다.

## 비교용 복사

통합 AI 1회 결과와 수동 PSOS 최종 결과가 모두 준비되면 `두 결과 같이 복사`를 누른다. 클립보드에는 다음 형식으로 들어간다.

```text
# 통합 AI 1회 결과
...

---

# 수동 PSOS 4단계 결과
...
```

이를 ChatGPT에 붙여 도메인 절차, 고정 조건, 예외 처리, 출력 계약의 실질적인 차이를 비교한다.
