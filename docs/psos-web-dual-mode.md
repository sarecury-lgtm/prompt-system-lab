# PSOS web dual mode

로컬 PSOS 작업실은 두 실행 모드를 제공한다.

## Codex 전체 실행

일반 자연어 요청을 입력한다. 기존 PSOS가 Goal Ledger, 경로 선택, 모델 정책, 검색, 읽기 전용 실행 또는 승인된 파일 변경을 처리한다.

- Codex CLI 필요
- 라우팅·조사·분석·코드·파일 작업 가능
- 읽기 전용과 승인된 파일 변경 지원
- 실행 기록을 `runs/`에 보존

## Codex 없는 프롬프트 생성

평소에는 `어떤 프롬프트가 필요한가요?` 한 칸만 입력한다. 브라우저가 그 요청을 목표로 사용하고 공통 작업 절차와 완료 조건을 붙인 뒤, 서버의 `problem_solving_prompt_renderer.py`가 최종 프롬프트를 결정론적으로 만든다.

- Codex와 모델 호출 없음
- 웹 검색 없음
- 파일 변경 없음
- 같은 입력은 같은 결과
- 보이는 필수 입력은 요청 한 칸뿐
- `꼭 지킬 조건`은 선택 사항
- 핵심 절차·완료 조건·보조 입력 등은 `세부 설정`에서 필요한 경우에만 직접 지정
- 결과는 일반 PSOS 실행 기록에 저장되지 않음

이 모드는 모델 없이 작동하므로 요청의 도메인 절차를 새로 추론하지 않는다. 세부 설정을 비우면 다음 공통 절차를 사용한다.

1. 사용자의 요청에서 최종적으로 필요한 결과를 파악한다.
2. 요청에 포함된 조건과 제공 자료를 기준으로 실제 작업을 수행한다.
3. 결과를 검토하고 사용자가 바로 쓸 수 있는 최종 답을 제시한다.

완료 조건 기본값은 `사용자가 요청한 결과가 바로 사용할 수 있는 형태로 제공된다.`이다. 도메인별 분석 순서가 중요한 프롬프트만 세부 설정에서 절차를 직접 보완한다.

## 실행

```powershell
cd C:\Users\jeong\prompt-system-lab
git switch main
git pull
python -B .\scripts\problem_solving_web.py --open-browser chrome
```

화면 상단의 `실행 엔진`에서 두 모드를 전환한다. 서버 주소는 기본적으로 `http://127.0.0.1:8765/`이며 외부 주소에는 바인딩되지 않는다.
