# PSOS web dual mode

로컬 PSOS 작업실은 두 실행 모드를 제공한다.

## Codex 전체 실행

일반 자연어 요청을 입력한다. 기존 PSOS가 Goal Ledger, 경로 선택, 모델 정책, 검색, 읽기 전용 실행 또는 승인된 파일 변경을 처리한다.

- Codex CLI 필요
- 라우팅·조사·분석·코드·파일 작업 가능
- 읽기 전용과 승인된 파일 변경 지원
- 실행 기록을 `runs/`에 보존

## 빠른 템플릿 생성

이 모드는 AI가 프롬프트를 설계하는 기능이 아니다. 사용자가 적은 작업을 공통 PSOS 틀에 넣어 복사용 초안을 즉시 만드는 결정론적 템플릿 조립기다.

- Codex와 모델 호출 없음
- 웹 검색 없음
- 파일 변경 없음
- 같은 입력은 같은 결과
- 전문적인 Goal Ledger·Prompt Build Brief 설계 단계는 생략
- 보이는 필수 입력은 요청 한 칸뿐
- `꼭 지킬 조건`은 선택 사항
- 핵심 절차·완료 조건·보조 입력 등은 `세부 설정`에서 필요한 경우에만 직접 지정
- 결과는 일반 PSOS 실행 기록에 저장되지 않음

사용자가 `차트 분석 프롬프트를 만들어 줘`처럼 입력하면 템플릿의 목표는 다시 프롬프트를 만들라는 지시가 아니라 `차트를 분석한다`는 실제 작업으로 정규화한다. 이 정규화는 제한적인 문구 처리이며 도메인 절차를 새로 추론하지는 않는다.

세부 설정을 비우면 다음 공통 절차를 사용한다.

1. 사용자 요청에서 실제로 수행해야 할 작업과 최종 판단을 파악한다.
2. 제공된 자료와 조건만 사용해 요청한 작업을 직접 수행한다.
3. 핵심 근거, 주요 위험, 결론이 바뀌는 조건과 다음 행동을 포함해 바로 쓸 수 있는 결과를 제시한다.

완료 조건 기본값은 `사용자가 요청한 실제 작업의 결과가 제공되며, 프롬프트를 다시 만들라고 요구하지 않는다.`이다. 도메인별 분석 순서가 중요한 경우에는 세부 설정을 직접 보완하거나 Codex 전체 실행을 사용한다.

### 생성 결과 사용

생성된 결과는 자동으로 실행되지 않는다. 결과 아래에서 다음 중 하나를 선택한다.

- `복사`: 최종 템플릿을 클립보드에 복사
- `다음 Codex 요청에 1회 적용`: Codex 전체 실행 화면으로 이동한 뒤, 다음 실제 요청 앞에 템플릿을 한 번만 붙여 실행

1회 적용된 템플릿은 해당 요청을 제출하는 순간 브라우저 저장소에서 제거된다.

## 실행

```powershell
cd C:\Users\jeong\prompt-system-lab
git switch main
git pull
python -B .\scripts\problem_solving_web.py --open-browser chrome
```

화면 상단의 `실행 엔진`에서 두 모드를 전환한다. 서버 주소는 기본적으로 `http://127.0.0.1:8765/`이며 외부 주소에는 바인딩되지 않는다.
