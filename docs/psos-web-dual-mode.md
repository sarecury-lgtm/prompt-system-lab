# PSOS web execution modes

로컬 PSOS 작업실은 세 가지 실행 방식을 제공한다.

## Codex 전체 실행

일반 자연어 요청을 입력한다. 기존 PSOS가 Goal Ledger, 경로 선택, 모델 정책, 검색, 읽기 전용 실행 또는 승인된 파일 변경을 처리한다.

- Codex CLI 필요
- 라우팅·조사·분석·코드·파일 작업 가능
- 읽기 전용과 승인된 파일 변경 지원
- 실행 기록을 `runs/`에 보존

## 빠른 템플릿 생성

이 모드는 AI가 프롬프트를 설계하는 기능이 아니다. 사용자가 적은 작업을 공통 PSOS 틀에 넣어 복사용 초안을 즉시 만드는 결정론적 템플릿 조립기다.

- Codex와 모델 호출 없음
- 웹 검색 없음
- 파일 변경 없음
- 같은 입력은 같은 결과
- 전문적인 Goal Ledger·Prompt Build Brief 설계 단계는 생략
- 보이는 필수 입력은 요청 한 칸뿐
- `꼭 지킬 조건`은 선택 사항
- 핵심 절차·완료 조건·보조 입력 등은 `세부 설정`에서 필요한 경우에만 직접 지정
- 결과는 일반 PSOS 실행 기록에 저장되지 않음

사용자가 `차트 분석 프롬프트를 만들어 줘`처럼 입력하면 템플릿의 목표는 다시 프롬프트를 만들라는 지시가 아니라 실제 작업을 수행하는 목표로 제한적으로 정규화한다. 이 처리는 도메인 절차를 새로 추론하지 않는다.

세부 설정을 비우면 다음 공통 절차를 사용한다.

1. 사용자 요청에서 실제로 수행해야 할 작업과 최종 판단을 파악한다.
2. 제공된 자료와 조건만 사용해 요청한 작업을 직접 수행한다.
3. 핵심 근거, 주요 위험, 결론이 바뀌는 조건과 다음 행동을 포함해 바로 쓸 수 있는 결과를 제시한다.

생성 결과 아래에서 `복사`하거나 `다음 Codex 요청에 1회 적용`할 수 있다. 1회 적용된 템플릿은 다음 요청을 제출하는 순간 브라우저 저장소에서 제거된다.

## 수동 PSOS 4단계

예전에 ChatGPT와 여러 번 왕복하던 방식을 비교용으로 복원했다. 서버가 AI를 호출하지 않으며, 각 단계 지시문을 사용자가 복사해 원하는 AI에 보내고 결과를 다음 칸으로 옮긴다.

1. 원래 요청을 입력하고 `라우터 지시문`을 복사한다.
2. AI가 반환한 Goal Ledger JSON을 붙이고 `Brief 컴파일러 지시문`을 복사한다.
3. AI가 반환한 Prompt Build Brief JSON을 붙이고 `최종 실행기 지시문`을 복사한다.
4. 생성된 최종 프롬프트를 붙여 넣는다.

각 단계 입력은 브라우저에 임시 보존된다. 수동 최종 결과는 복사하거나 다음 Codex 요청에 한 번 적용할 수 있다.

### 빠른 템플릿과 비교

수동 화면 하단에는 다음 두 결과가 나란히 표시된다.

- 가장 최근에 생성한 빠른 템플릿
- 수동 PSOS 4단계의 최종 프롬프트

따라서 같은 원래 요청을 두 방식에 사용한 뒤, 길이보다 도메인별 절차·고정 조건·질문 규칙·출력 계약이 실제로 달라졌는지 직접 비교할 수 있다.
