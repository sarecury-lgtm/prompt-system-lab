# PSOS Visual Evidence Collector

웹페이지에서 사용자가 직접 고른 이미지를 현재 PSOS 실행의 Evidence Bundle에 추가하는 Chrome 확장 프로그램이다.

## 권한 경계

- 현재 탭에만 일시 접근한다.
- `http://127.0.0.1:8765`와 `http://localhost:8765`의 로컬 PSOS 서버에만 전송한다.
- 사용자가 체크한 이미지만 전송한다.
- 한 번에 최대 24장을 전송한다.
- 웹페이지를 수정하거나 자동 구매·로그인·후기 작성은 하지 않는다.

## 설치

1. `chrome://extensions`를 연다.
2. 오른쪽 위 `개발자 모드`를 켠다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누른다.
4. 이 폴더를 선택한다.

```text
extensions/psos-visual-evidence
```

## 사용

1. PSOS 품질 서버를 실행하고 결과를 하나 만든다.
2. 결과 화면에 표시된 `psos-...` 실행 ID를 확인한다.
3. 사진을 볼 웹페이지를 열고 필요한 이미지가 로드되도록 스크롤한다.
4. 확장 프로그램 아이콘을 누른다.
5. 실행 ID, 후보명, 사진 출처 유형을 입력한다.
6. 필요한 사진만 체크하고 `선택한 사진 추가`를 누른다.
7. PSOS 결과 화면을 새로고침한다.

후보명은 자동 추측하지 않는다. 같은 사진도 사용자가 다른 후보에 명시적으로 연결하면 별도 근거로 저장된다.

## 저장되는 정보

- 후보명
- 판매자 제공 / 구매자 후기 / 기사·편집 자료 / 미확인 구분
- 원본 이미지 URL과 최종 응답 URL
- 원본 페이지 URL과 제목
- 이미지 크기
- `alt` 텍스트와 주변 문맥
- 수집 시각
- 로컬 파일 경로, 실제 MIME, 바이트 수, SHA-256

이미지는 가능하면 현재 run의 아래 경로에 콘텐츠 주소 방식으로 보존한다.

```text
evidence/images/<sha256>.<확장자>
```

장당 최대 12MB, 한 번 가져오기 전체 최대 64MB다. JPEG·PNG·GIF·WebP·AVIF만 허용하고 응답 MIME과 실제 파일 형식이 일치해야 한다. 사설·로컬·예약 주소와 인증 정보가 든 URL은 내려받지 않으며 리다이렉트도 다시 검사한다.

다운로드가 실패해도 선택한 근거 자체를 지우지는 않는다. 원본 URL과 실패 이유를 `unavailable` 상태로 남겨 사용자가 원본 페이지에서 다시 확인할 수 있게 한다.
