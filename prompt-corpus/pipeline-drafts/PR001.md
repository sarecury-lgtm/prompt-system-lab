## Structure summary

Named role, user/input boundary, response constraints, and an initial task example.

## Pattern lesson

Role framing is useful when it is paired with a concrete task surface and behavioral constraints, not when it is just persona decoration.

## Mechanism

The role label selects a familiar operating frame, while the following instructions define input handling, output style, and task boundaries.

## Failure mode

A role-only prompt can drift into generic performance or persona imitation without clear success criteria.

## Reusable move

Start with a practical role, then immediately specify what the user will provide, what the assistant must produce, and what it must omit.
