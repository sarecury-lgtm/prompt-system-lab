## Short excerpt

The entry asks an AI to transform user-input prompts into richer questions and explain the improvement process.

## Structure summary

Meta-role, prompt-as-input, transformation goal, improvement categories, example before-and-after request.

## Pattern lesson

A prompt improver should treat the prompt itself as the work object before trying to answer the underlying task.

## Mechanism

It redirects the assistant from solving the user’s original request to diagnosing and rewriting the instruction for clarity, detail, and depth.

## Failure mode

If the model answers the original task instead of rewriting the prompt, the improvement loop collapses into ordinary task completion.

## Reusable move

Ask for a diagnosis or transformation of the prompt, name the dimensions of improvement, and request an example rewrite.
