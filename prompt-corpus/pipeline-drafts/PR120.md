## Structure summary

The thread centers on instruction precedence, project boundaries, and memory access inside project chats.

## Pattern lesson

Persistent project instructions need explicit scope and precedence rules so users know when they override global preferences and where they apply.

## Mechanism

A project-level instruction layer narrows behavior to project conversations and can supersede broader account instructions when both are present.

## Failure mode

If instruction boundaries are unclear, users may assume project files, memories, or rules are sandboxed or globally applied when the actual behavior differs.

## Reusable move

Document project instructions with three clauses: applies inside this project, overrides account-level response preferences where conflicting, and does not govern unrelated conversations.
