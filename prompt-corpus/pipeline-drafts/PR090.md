## Structure summary

Current repo positions Open Interpreter as a terminal coding agent with switchable harnesses, local state, permission controls, and project instruction support.

## Pattern lesson

Persistent Project Instruction works best when project-local instructions, permissions, session state, and harness selection are explicit parts of the agent runtime.

## Mechanism

AGENTS.md and local configuration give the agent durable project context, while sandboxing and approvals define what actions require boundaries at execution time.

## Failure mode

If persistent instructions are invisible or mixed across harnesses, the agent may follow the wrong project conventions or assume permissions it does not have.

## Reusable move

Load project instructions from a named local file, combine them with explicit permission/sandbox settings, and state which harness or mode is active before acting.
