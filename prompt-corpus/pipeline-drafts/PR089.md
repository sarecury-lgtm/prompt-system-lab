## Short excerpt

Roo Code exposes mode-specific roles and capability groups, including issue fixing, PR fixing, merge resolving, docs extraction, and issue investigation.

## Structure summary

Mode routing plus permission groups: each mode has a role, when-to-use description, and allowed capabilities such as read, edit, command, or MCP.

## Pattern lesson

A Coding-Agent Workflow benefits from explicit mode selection: separate investigation, planning, implementation, debugging, and documentation extraction into roles with different permissions.

## Mechanism

Roo uses mode metadata and rule sections to constrain what the agent should do, which files it may edit, when to ask follow-up questions, and how commands should respect the project base directory.

## Failure mode

Without mode boundaries, a code agent can mix investigation with editing, modify restricted files, or over-ask the user instead of using available project context.

## Reusable move

Define modes with roleDefinition, whenToUse, allowed tool groups, and file patterns, then route user requests into the narrowest mode that can complete the task.
