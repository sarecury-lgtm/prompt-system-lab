## Pattern lesson

Evaluation rubrics often need supporting infrastructure: comparable model runs, versioned prompts, cost visibility, A/B routing, and stakeholder-friendly review surfaces.

## Mechanism

Prompt variants are made testable by exposing them in a UI, fetching exact versions through APIs, and routing variants through dynamic rules for controlled comparison.

## Failure mode

Without versioned retrieval and controlled A/B rules, teams cannot reliably connect prompt changes to output quality, cost, or rollout behavior.

## Reusable move

Define prompt tests with version IDs, model matrix, cost capture, side-by-side outputs, and rollout rules tied to persona or team segments.
