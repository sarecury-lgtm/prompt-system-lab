## Pattern lesson

A coding-agent workflow benefits from a staged contract: clarify uncertainty, plan required code units, traverse from entrypoint through imports, implement complete files, and verify architecture before reporting completion.

## Mechanism

The agent is guided by persistent preprompts that constrain how it interprets requirements, orders file work, and checks completeness.

## Failure mode

If the agent skips clarification, entrypoint traversal, dependency definitions, or final architecture checks, generated projects can be incomplete or internally inconsistent.

## Reusable move

Use a coding prompt scaffold with phases for clarify, identify core units, edit complete files, include dependencies, validate cross-file compatibility, and finish with an explicit completion report.
