## Short excerpt

Aider's edit-block prompt requires asking for missing files, explaining changes briefly, and returning exact SEARCH/REPLACE blocks for provided files.

## Structure summary

Prompt suite with base behavior, edit-block editing, whole-file editing, read-only repo context, file-added-to-chat permissions, and git/edit status messages.

## Pattern lesson

A Coding-Agent Workflow can reduce edit risk by separating read-only repo context from editable files and requiring deterministic patch formats.

## Mechanism

Aider constrains edits to files added to the chat, demands exact search text, uses full paths, and gives different coders different output contracts such as SEARCH/REPLACE blocks or whole-file listings.

## Failure mode

If the agent edits files that were only summarized or emits non-exact search blocks, patches can target stale or wrong content.

## Reusable move

Mark context files as read-only, require the user or tool to promote files into the editable set, then emit changes in a strict patch grammar with exact matching rules.

## Safety / reproduction note

The prompt files demonstrate editing protocol, but they do not by themselves verify runtime patch application success.
