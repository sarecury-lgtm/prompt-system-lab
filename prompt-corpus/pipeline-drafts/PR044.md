## Short excerpt

Run same or similar prompts across multiple chatbots, compare responses, and merge the strongest parts.

## Structure summary

The article defines a multi-bot comparison workflow, lists model strengths, and provides example prompts with what-to-compare criteria.

## Pattern lesson

A lightweight evaluation rubric can be built by running the same task across models and comparing outputs against task-specific anchors.

## Mechanism

Different models expose different strengths; comparison criteria make quality differences visible before combining or selecting outputs.

## Failure mode

Without explicit comparison anchors, multi-model prompting can become subjective cherry-picking rather than repeatable evaluation.

## Reusable move

For each prompt, predefine comparison anchors such as accuracy, structure, specificity, tone, usefulness, citations, or practicality, then score outputs side by side.
