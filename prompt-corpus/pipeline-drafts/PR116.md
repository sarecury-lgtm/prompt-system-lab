## Pattern lesson

Persistent prompt instructions need release history and experiment records when they become part of production behavior.

## Mechanism

Git history, output logs, side-by-side comparisons, and eval runs connect a prompt version to observed behavior before rollout.

## Failure mode

Small prompt edits can create unexpected regressions when versions are not tied to releases or checked against eval runs.

## Reusable move

Record prompt version, release linkage, experiment variant, output snapshot, evaluator result, and approval owner for every production prompt change.
