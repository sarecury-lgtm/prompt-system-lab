# Result Inbox

Codex 구현 작업의 짧은 인수인계 결과만 보관한다. 세부 실행 로그나 생성 원문을 이 디렉터리에 복제하지 않는다.

## 사용 규칙

1. `CODEX_QUEUE.md`에서 `status: ready`인 패킷만 실행한다.
2. 완료 또는 보류 시 `RESULT_TEMPLATE.md`를 복사해 `<task_id>-RESULT.md`로 저장한다.
3. 변경 파일과 테스트 결과는 재현 가능한 경로·명령으로 기록한다.
4. 채팅 판단이 필요한 질문은 기술 세부가 아니라 선택의 목적·범위·위험을 묻는다.
5. 다음 작업 후보는 하나만 적고 자동 실행하지 않는다.
