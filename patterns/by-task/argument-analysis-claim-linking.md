# Candidate Pattern — Argument Claim Linking

Status: exploratory candidate; not runtime-promoted.

Evidence:

- Source candidate: PR085
- Pilot: `2026-07-22-arg-exploratory`
- Best observed use: long, nested, multi-speaker, or claim-dense argument threads
- No unique gain observed for short single-claim disputes

## Trigger

Apply only when replies can easily be attached to the wrong claim or when one speaker makes several nearby but non-equivalent claims.

## Reusable move

```text
Split each speaker's statements into claim units. Connect every reply to the exact prior claim it addresses. For each claim, separate stated evidence, hidden assumptions, support range, alternative explanations, and external facts that still require verification.
```

## Do not apply

- simple one-claim questions
- ordinary factual explanations with no reply graph
- cases where the added claim map does not change the judgment

## Main risk

Turning a short disagreement into a large analysis grid with no substantive gain.
